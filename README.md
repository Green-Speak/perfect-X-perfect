# perfect-X-perfect
A student project (which name originally should have been perfect², sadly Github does not allow that) to learn how to make code run quicker.
I will build a project folder in which I try to tackle a rather trivial problem, checking if a number is a perfect square. But how many numbers can we check in 1 second? 
This is much more interesting (in my opinion)

I will use C for the computations and Python for the data generation and verification. I am going to document most of my thought process and the reasoning behind my implementations.
